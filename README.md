## Overview

KULT generates sounds through spectral-partials synthesis, stacking up to hundreds of sine partials with independent envelope, phase, and modulation per partial for deeply evolving pads and textures.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Dawesome KULT** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Spectral Engine** | Up to 512 sine partials with individual amplitude and phase control |
| **Morph Sequencer** | Sequence spectral snapshots to create evolving timbre animations |
| **Chord Memory** | Lock chords and voice-lead smoothly between spectral snapshots |
| **Macro Knobs** | Six assignable macros for real-time spectral transformation |
